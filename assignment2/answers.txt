==================================================
التجربة 1: فحص لون عنوان الكورس (Specificity)
==================================================
- التوقع قبل الاختبار:
 سيظهر العنوان باللون البنفسجي (purple) لأن المحدد #course-title يحمل أعلى specificity بين القواعد المطبقة.
- النتيجة والملاحظة: ظهر العنوان باللون البنفسجي 
(purple)، وفي DevTools -> Styles تظهر قواعد #course-title و .title و h1 و .course-card مع شطب الأقل أولوية حسب specificity.
- السبب: الـ ID selector (#course-title) له specificity أعلى (1,0,0) من الـ 
class selector (.title بـ 0,1,0) ومن الـ type selector (h1 بـ 0,0,1)، بينما (.course-card) ينطبق على العنصر الأب ولا يغلب قواعد تطابق العنصر نفسه مباشرة.
 ولا تفوز قاعدة h1 رغم وجودها بعد .title و .course-card لأن specificity يسبق source order عند اختلاف الأوزان.

==================================================
التجربة 2: تغيير ترتيب قاعدتين (Source Order)
==================================================
- التوقع قبل الاختبار
: بعد تعطيل #course-title وإضافة .title { color: orange; } في نهاية الملف سيفوز اللون البرتقالي (orange)؛ وعند نقلها قبل .title { color: green; } سيفوز اللون الأخضر (green).
- النتيجة والملاحظة:
  1) عند تعطيل #course-title وإضافة .title { color: orange; } في نهاية styles.css: أصبح لون العنوان برتقاليًا (orange).
  2) عند نقل .title { color: orange; } إلى ما قبل .title { color: green; }: أصبح لون العنوان أخضر (green).
- السبب: القاعدتان لهما الـ specificity نفسه (.title)، وعند تساوي specificity يفوز آخر إعلان في ترتيب المصدر (Source Order) — أي القاعدة التي تأتي لاحقًا في الملف.

==================================================
التجربة 3: تتبع لون الفقرتين (Inheritance)
==================================================
- التوقع قبل الاختبار:
 كلتا الفقرتين (<p> المباشرة و<p> داخل .details) ترثان اللون الرمادي #374151 من .course-card بشكل افتراضي، وعند تطبيق قاعدة تحصر الوراثة بالفقرة المباشرة سيختلف سلوك الفقرة الثانية.
- النتيجة والملاحظة:
 في DevTools -> Computed، كلا الفقرتين كانتا ترثان color: rgb(55, 65, 81) (#374151) من .course-card افتراضيًا. وبعد إضافة القاعدة .course-card > p { color: inherit; }، أخذت الفقرة المباشرة (Learn how the browser chooses a style.) القيمة الموروثة صراحةً، بينما بقيت الفقرة داخل .details ترث اللون تلقائيًا من .course-card عبر سلسلة التوريث (لأنها ليست ابنًا مباشرًا لـ .course-card).
- السبب: الخاصية color موروثة افتراضيًا في CSS. استخدام Child Combinator (.course-card > p) يستهدف فقط عناصر <p> التي يكون والدها المباشر هو .course-card، بينما Descendant Combinator (.course-card p) يستهدف أي <p> بداخلها مهما كان عمق التداخل. اخترت Child Combinator (>) لأن المطلوب هو استهداف الفقرة المباشرة فقط دون غيرها.

التجربة 4: اختبار الرابط (:hover و :focus-visible)
==================================================
- التوقع قبل الاختبار: عند تمرير الماوس على الرابط يتغير لونه إلى الأحمر، وعند الوصول إليه بزر Tab تظهر حوله حلقة تركيز واضحة (outline).
- النتيجة والملاحظة:
  - عند تمرير الماوس (:hover): تغير لون نص الرابط إلى اللون الأحمر (#dc2626).
  - عند الضغط على Tab للوصول للرابط (:focus-visible): ظهر إطار خارجي أزرق واضح (#2563eb) بإزاحة 2px حول الرابط.
- السبب: الحالة :hover تتفعل عند مؤشر الفأرة فوق العنصر، بينما :focus-visible تتفعل عند التركيز على العنصر بطريقة تستدعي إظهار مؤشر التركيز (مثل التنقل بلوحة المفاتيح عبر Tab) دون إزعاج النقر بالماوس.
